# 2026-11-02 卡 E2s：睡觉钟并成一个（回话那边跟着过日子那边睡没睡）

这张只做讨论 v4 的第 1 条：两个睡觉钟对不上。改的是 `attention.py`、`mixin_attention.py`（只
`_decision` 里夜里那一段）、`mixin_group_browse.py`（只 `_group_action` 的夜里那一行）、
`life_loop.py`，加上新测试 `tests/test_one_sleep.py` 和这份说明。

## 1. 睡没睡只看一处

新的 `life_loop.asleep(plugin, now)` 就是过日子那边的判断：`state['sleep']` 还没到 `end`，或者
此刻是睡觉、还没到结束时间（`sleeping(item)`）。它只在 `life_loop` 开着时给答案；关着时回
`False`。

- `mixin_attention._decision`：`life_loop` 开着时用 `asleep`，`attention.is_night` 不再问；
  关着时照旧看 01:00–08:25。
- `mixin_group_browse._group_action`：同一把尺；关着时照旧看 `attention.is_night`。
- 睡着、没被叫：不开口（跟以前夜里一样）。醒着、没被叫：照白天办，不再因为钟点就不开口。

## 2. 睡着被叫：吵醒的劲怎么算

`attention.wake_check(calls, sleepiness, now)`，纯函数。每一笔被叫记成 `(ts, 分量)`：

- 分量：他（`owner_qq`）1.0；别人 `0.3 + 0.7 * familiarity`（`attention.wake_weight`）。
- 吵醒的劲 = 每一笔的 `分量 * exp(-(now - ts) / WAKE_FADE)` 加起来。
- 劲 ≥ `WAKE_BASE + WAKE_SLEEPY * sleepiness` 就醒：越困越难叫醒。

常量放在一起（`attention.py` 顶部），注释写了往哪调更容易醒：`WAKE_BASE`、`WAKE_SLEEPY` 调低，
或 `WAKE_FADE` 调长，都更容易醒；`WAKE_SLEEPY` 调高，困不困更算数。起步值
`WAKE_FADE=600` 秒、`WAKE_BASE=0.7`、`WAKE_SLEEPY=0.9`。

醒了：

- 跟现在一样，`mood_events_enabled` 开着时 `core.mood_event("woken")`；
- `life_loop.wake_up(plugin, now)`：把 `state['sleep']['end']` 和睡觉那件事的结束都改成现在，并
  留一笔“被叫醒”，让下一分钟的 `tick` 走睡醒那条路：`body` 结算睡了多久，她照着“被叫醒了”
  想一次（E2 的“你睡着的时候：”那段也在）；
- 叫醒她的那条消息照常回；
- 醒了就是醒了，不再有 `awake_until` 那 20 分钟。

## 3. 没叫醒的记下来

睡着时被叫、没醒，`life_loop.note_missed` 往 `state['missed']` 记一笔：地方的键、时间、熟不熟
（三档：很熟 / 一般 / 不认识，`attention.wake_tier`）。不记原话，不记号码。醒来那次的材料里，
E2 的“你睡着的时候：”后面加一行，例如

    群1 有人叫了你 2 次（一个很熟的，一个不认识的）

地方只编号（`群1`、`私聊1`），不写群号；群里说了什么也不放进来，她醒了自己去看（等 G1b 的
“看看群”）。她醒来想过以后，`missed` 就清掉。

## 4. `life_loop` 关着时照旧

`asleep` 回 `False`，`wake_up` / `note_missed` 也不做事；`_decision` 还是 01:00–08:25、
`night_gate`（10 分钟里被叫 3 次才醒，之后 `NIGHT_SLEEP_AGAIN_MINUTES` 内一直回），
`_group_action` 还是看钟点。老的 `night_calls` 只有时间，`attention.wake_calls` 把它读成满分量的一
笔，按年龄淡掉。

## 检查

`tests/test_one_sleep.py` 对着卡里的 9 项：`life_loop` 开着 23:00 睡着不问她；02:00 醒着照白天
办；困与不困、他叫与不认识的人叫；隔很久的一笔淡掉；醒了有起床气、下一分钟理由是“被叫醒了”、
那条照常回；`missed` 没有原话没有号码、材料里是“群1 有人叫了你…”且没有群号、想过以后清掉；
