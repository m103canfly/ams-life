# 回放人设接线和已知私事暗示检查

回放首答现在使用从 AstrBot 只读取得的人设，重说沿用原请求的人设。按 local / 其他 runner 的实际配置路径读取；指定正式来源后，人设未选中、缺失、空白或读取失败都终止，不再回退占位提示。SQLite 使用只读连接，并读取已提交的 WAL 内容。无正式来源的假模型回放保留原占位提示。工具仍只读取默认人设；正式使用前须确认目标会话没有不同的人设覆盖。

发出前检查为“这里不能讲”条目增加明确标记，和仅“不点名”区分。复用原检查及一次重说流程，补已知的承认私事、承认私下来源后拒绝展开的说法；仍不过、重说失败或条件不足时停止事件、清空响应文本和链，不留原答。普通行程不便、一般隐私原则、本人允许的私聊、无私事条目及关闭开关保持原行为。

检查日志仅记原因代码、异常类型和计数，不记录异常原文或来源标识（部分旧标识可能含原文）。`hint` 是新增的检查原因；调用方仍按 `leak` 统一处理。失败重说也计入 `redo_calls`，不增加重试次数或新的模型调用类型。

新增离线用例在旧代码上先失败：已知暗示、人设首答和重说接线、正式来源失败拒绝、以及被挡响应链清理。假发送出口、保存历史、手机、记忆均检查；假模型异常携带编造敏感标记，断言日志未回显。人设测试只用编造配置和数据库，模型连接数为零。未重录 golden，不引入依赖或配置项。

本次短语检查只覆盖已知说法，不能保证覆盖所有语义暗示。不改变“别外传”的出处语义，不打开全局记忆，不执行付费回放或装机。回放原有本机嵌入测试在带代理的执行环境会被网络闸拒绝，测试时仅为进程设置本机 NO_PROXY；浏览器驱动的既有失败另列在施工回报中。
