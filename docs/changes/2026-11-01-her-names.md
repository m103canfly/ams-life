# Her names: drop the character name (card P1, 2026-11-01)

The owner's new persona makes 小爱 a group member who likes the Wuthering Waves character 爱弥斯; she is not that character. So the character name no longer counts as someone calling her.

- `attention.HER_NAMES` and the `her_names` default in `_conf_schema.json` keep only "小爱".
- README line 3 says she likes the character.
- `tests/test_attention.py`: the old assertion that the character name calls her is removed; `HerName.test_character_name_is_not_her_name` checks that talking about the character (for example "爱弥斯伤害好高") does not.
- Goldens: unchanged.
- An existing `her_names` in a running config overrides the default; on install day the dispatcher checks it by hand.
