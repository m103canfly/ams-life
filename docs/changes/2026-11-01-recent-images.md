# Recent pictures from anyone

When addressed without a picture, consider the two newest unseen pictures from the
same conversation within two minutes, with the caller's picture first. Identify the
sender in the prompt, applying the usual model-facing name handling. QQ stickers are
excluded from recent pictures. Existing retention checks and image recognition gates
still apply; cached captions retain the original sender for forgetting.
Pictures from other senders are not added to the sticker library by this look,
because that library otherwise attributes them to the caller.

No new switch or dependency. No pages or other card-external files changed.
The full suite was not run as directed; targeted results are reported separately.
