# Owner-only Qzone posts

Add a default-off `qzone_enabled` setting and module functions for posting and deleting
owner-only Qzone posts. The OneBot adapter validates both actions and only reads generated
photos directly in the selfie folder. Posts pass red line, owner-rule and privacy checks.
The stored record contains a hash rather than the post text. A daily count is stored
separately so deleting a post cannot reset the limit. A send reserves its quota before the
network call; an uncertain failure can consume a slot, avoiding accidental excess sends.

The new program alone is in scope; AstrBot parity is not covered by this card. No plugin
methods or golden fixtures are changed. The generic OneBot action test excludes the two
actions because they require their own parameters. No full suite is requested.
Offline validation: `test_qzone` (6), `test_messenger` (25), `test_onebot_messenger` (41),
`test_golden` (2), and `test_basics` (11) passed. `test_golden_standalone` runs outside
the sandbox by owner request.
