# Move 5e-5b: standalone entry point

## Why

The standalone program needs to connect her neutral turn runner, local panel,
configuration, persona, history, keys and OneBot server.

## Changes

Add `app.py`, an AstrBot compatibility package and offline tests. The entry point
uses `keys.dat`, refuses live or inconsistent data directories, starts the panel
without OneBot when required keys are missing, and closes its resources on stop.
It enables `self_decide` on the instance only; the configuration file is unchanged.
Keys that cannot be decrypted are treated as missing, with a warning naming the key;
the panel remains available for replacing a required key, and vision does not block OneBot.
The plugin, existing tests and golden files are unchanged. No new dependency or
switch is added beyond the entry point's command-line options.
