# Weather

Her prompt can include today's weather from Open-Meteo. The place and coordinates
default to empty; the place is used only in the prompt. With coordinates unset,
no weather request or weather line is produced. Weather also appears when the
photo switch is off, as a separate line.

The existing five-minute loop starts during enabled standalone startup inside
the event loop and does not depend on photo or autonomy switches. It fetches in
a worker thread when needed. A same-day cache avoids further requests; failures
are retried at least three hours apart, at most three attempts per day. Attempt
timing is saved separately so restarting does not reset the limit. The weather
cache contains no place or coordinates. Requests have a five-second timeout,
do not follow redirects, and read at most 64 KiB; a full buffer is rejected.
The turn only reads the cache. Warnings contain the error type, not its message.

The two coordinates use nullable float schema entries. Configuration loading and
saving accept null only for explicitly nullable floats; other float validation
is unchanged. The migration tests retain their existing assertions.
