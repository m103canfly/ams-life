# ams-life 改造计划（摘要）

完整方案在维护者的文档里，这里是公开的摘要，随进度更新。最后更新：2026-10-27。

## 目标

- **一个她**：所有群和私聊共用一个身体（心情、几种冲动）和一份记忆，不再一个会话一个分身。
- **记忆带出处**：每条记忆记下在哪、和谁有关、当众还是私下。她都记得，但私下听来的不在别处讲；群友说“忘记我”就真删。
- **她自己挑地方**：一个注意力循环在几个群和私聊之间挑地方去看、决定在哪开口。
- **心只由她写**：身体由程序算，她怎么理解自己只写在她自己的本子里，开发者和面板都不替她写。

## 身体：电子幽灵的身体

保留心情三轴（快乐、兴奋、掌控感）和回落、压力、想说话、好奇、无聊；新加“想被看见”；“疲劳”改成“说多了”（防刷屏）。
去掉昼夜犯困、水分、温度、需求层次和全局“信任”数（信任只放在对具体某个人的关系里）。
不再每轮往提示里塞一行数字，改成一两句只描述、不下指令的话；也不再要求模型在回复末尾带 `<bc>` 标签。
